# Attribution and license status

TT-Bootload contains TerrainTronics firmware and host-tool changes alongside
WCH SDK code, headers, startup code, linker scripts, and reference documents.
Vendor copyright and usage notices are retained in the source files.

The WCH source notices state that the software, modified or unmodified, and
its binaries are for microcontrollers manufactured by Nanjing Qinheng
Microelectronics. Those notices continue to apply to the vendor material.

Upstream references:

- https://github.com/openwch/ch32v002_004_005_006_007
- https://github.com/openwch/arduino_core_ch32

No project-wide license has been selected for TerrainTronics-authored material.
Publishing these files does not by itself grant an additional license. Select
and document that license before describing the project as open source; retain
the vendor notices and distinguish their terms from the project's own terms.
